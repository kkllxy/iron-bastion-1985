# 余烬花圃：末日自走棋

原创 Three.js 单页自走棋。玩家在 5×9 草坪上购买、拖放、升星和嫁接变异植物，让阵容自动抵挡 15 波污染怪物。

## 运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5195`。

## 操作

- 鼠标/触控：点击商店购买；从培育盘拖到草坪；点击奖励卡选择强化。
- `1–5`：购买对应商店槽。
- `R`：花费 10 阳光刷新；`L`：锁定商店。
- `Q`：选择铲子，再点草坪植物回收。
- `E`：战斗中消耗肥料，全园短时强化。
- `空格`：开始本波；`Esc`：暂停/继续。

三株同类同星植物会自动升星。培育盘同时拥有“烬焰花 + 霜脉蕨”或“辉光芽 + 甲壳根”时可点击“嫁接”。三星植物会触发二选一变异。

## 构筑联动

- 日光植物邻接射手：攻击有概率回收阳光。
- 火系邻接冰系：转化为蒸汽范围攻击。
- 菌类形成三株相邻网络：共享攻速。
- 甲壳根前方、锯齿藤后方：触发根藤反伤。

## 验证

```bash
npm run build
npm test
npm run verify:visual
npm run verify:baselines
npm run verify:bot
npm run inspect:canvas
```

`window.__GARDEN_TEST__` 提供固定 seed、状态快照、确定性布阵和波次控制，仅用于 Playwright 复验。视觉基线分别覆盖 1280×720 桌面端和 iPhone 13 移动端。

## 素材与原创声明

`assets/concepts/` 内 7 张概念图仅作为色彩、光照和末日花园氛围参考。正式游戏角色均由基础几何体程序化构建，名称、造型和世界观为原创，不使用其他游戏的角色或美术资源。
