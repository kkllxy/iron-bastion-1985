# 质量报告

## 交付范围

- 完整状态机：标题 → 备战 → 商店/布阵/升星/嫁接 → 自动战斗 → 三选一奖励 → 失败重开/15 波通关。
- 内容：12 种植物、8 种普通敌人、3 个 Boss、5 条路线、15 波、4 种相邻联动、天气、遗物、肥料和铲子。
- 适配：桌面鼠标/键盘与移动端触控布局；所有玩家可见文字使用简体中文与本地系统中文字体栈。
- 表现：程序化 Q 版模型、投射物、命中光环、死亡碎片、镜头震动、天气/遗物 HUD 和合成/战斗程序化音效。

## 确定性设计

玩法随机数由 Mulberry32 固定 seed 驱动。测试钩子可以重设 seed、注入阵容、读取经济/星级/联动快照和推进波次。音频不参与玩法结算。

## QA 策略

- Playwright 是硬门禁：主菜单、商店购买、拖拽摆阵、暂停、固定 seed 升星、相邻联动、15 波机器人闭环、中文乱码/溢出与桌面/移动视觉基线。
- Canvas inspector 断言画布尺寸、截图字节量和浏览器错误。
- Midscene 未使用：当前环境没有可用的 Midscene 工具/模型配置；视觉语义由固定截图人工审阅，未作为硬门禁。
- Chrome DevTools MCP 未使用：验证未出现需要性能或 Console 根因诊断的异常。

## 已知风险

- Playwright 的 CI 机器人使用确定性“肃清本波”钩子快速穿过 15 波；普通敌人移动、阻挡、攻击、投射物碰撞与植物死亡由独立交互场景覆盖，但未按真实 12–18 分钟墙钟时间跑完整局。
- WebGL 截图可能因操作系统 GPU/字体抗锯齿产生少量像素差异，视觉阈值保留 2.5% 差异容忍。

## 最终验证结果（2026-07-30）

- `npm run build`：通过，TypeScript 严格检查与 Vite 生产构建成功。
- `npm test`：10/10 通过；桌面与移动端各覆盖机器人、中文/交互、升星/联动、真实战斗和视觉基线。
- `npm run verify:bot`：2/2 通过，桌面与移动端均跑通 15 波状态闭环。
- `npm run verify:visual`：2/2 通过，桌面与移动端视觉基线匹配。
- `npm run inspect:canvas`：通过，1280×720，截图 236954 bytes，Console 错误 0。

验证过程中发现并修复了单体投射物条件分支歧义，以及高倍速/低帧率下可能发生的碰撞穿透；修复后真实敌人生成、投射物命中、击杀计分、无损奖励流程已在两种 viewport 复验通过。
