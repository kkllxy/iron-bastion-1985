# 花园自走棋 — 开发需求词

先按 AGENTS.md 判断本任务需要 Playwright、Midscene.js、Chrome DevTools MCP 中的哪些工具；只使用
必要工具，并说明选择和跳过原因。诊断后必须回到确定性测试复验。

使用 threejs-game-director 技能，所有新文件和操作必须限制在本目录（`garden-autochess-glm/`）内，
不得修改、覆盖或删除父项目已有内容。

## 开发要求

创建一个可玩的高品质 Three.js 单网页游戏，并由 threejs-game-director 自动调用需要的玩法、图形、UI、
调试和 QA 技能，完成设计、开发、性能检查、桌面/移动端适配及全流程验证。不要只做静态场景或简单 Demo，
必须具备完整的开始、每局自走棋循环（商店→摆阵→合成→自动战斗→奖励）、失败重开和通关闭环。

## 实现内容

制作一款致敬《植物大战僵尸》横向路线克制 ×《背包乱斗》摆阵构筑自动结算、但完全原创主题与美术的 3D
俯视/斜俯视“末日花园自走棋”。主题为「变异植物抵抗污染怪物」，不得直接使用《植物大战僵尸》的名字、
角色和美术。玩家不实时操控战斗，而是通过买种子、摆花园、合植物构筑阵容，让植物自动抵挡怪物潮。

### 核心循环（每波重复）

1. 备战阶段：商店随机刷出“种子”，可购买、刷新、锁定、出售。
2. 摆阵阶段：把植物拖入草坪网格，位置与相邻关系决定加成。
3. 合成阶段：三株同类升星，或两种植物嫁接成新品种。
4. 战斗阶段：植物自动攻击来袭怪物，玩家仅能使用少量主动技能（铲子移除、肥料临时增益）。
5. 奖励阶段：在肥料 / 天气 / 遗物 / 变异中选一，进入下一波。

### 关键相邻联动示例（构筑深度来源）

- 产阳光植物旁放攻击植物：攻击附带阳光产出。
- 火属性旁放冰属性：嫁接合成蒸汽攻击。
- 蘑菇围成一圈：形成菌丝网络，共享攻速。
- 防御坚果后放藤蔓：被攻击时反伤。
- 三星植物：在两个变异方向中二选一，而非单纯加数值。

### 内容规模（首版原型）

- 5 条横向路线；
- 约 12 种植物（含产阳光、攻击、防御、辅助、嫁接品种）；
- 约 8 种普通敌人（不同路线、速度与特性）；
- 3 个 BOSS；
- 每局 15 波，单局约 12～18 分钟；
- 战斗中只有铲子、肥料两个主动操作。

系统需包含：阳光经济、商店刷新/锁定/升星、相邻联动加成、嫁接合成与变异构筑、遗物/天气效果、
草坪防线血量、波次进度、计分、暂停、失败重开、通关演出。

### 操作

- 鼠标：商店点击购买/刷新/锁定，拖拽植物摆放与合成，点击铲子/肥料；
- 快捷键：R 刷新、L 锁定、1–5 购买商店槽、Q 铲子、E 肥料、空格 开始本波；
- 触控：拖拽放置 + 底部按钮组。

### 中文显示要求

游戏内所有文字必须统一使用简体中文显示，包括：标题、主菜单/设置、HUD（阳光数、波次、植物星数、
合成提示、遗物栏、防线血量、关卡进度）、商店与道具说明、变异/遗物文案、按键提示、暂停/失败/通关结算。
中文字符须使用支持中文的字体，避免方块或乱码；移动端文案不得溢出或被遮挡。

画面需有统一末日花园美术方向、卡通 Q版变异植物与污染怪物模型、清晰 HUD、攻击/合成光效/升星/阳光
拾取/怪物死亡 VFX、音效与 BGM，以及良好的构筑反馈手感。

## 技术与验收

使用 Three.js + TypeScript + Vite。提供确定性测试钩子（固定商店随机种子可复现摆阵与战斗结算）、
运行诊断、生产构建、Playwright 交互测试、桌面与移动端视觉基线、画布非空检查和机器人游玩测试（用固定
种子跑通完整自走棋循环并断言经济/升星/相邻联动数值）。Playwright/视觉基线需专门校验中文文案正确渲染、
无乱码、无溢出遮挡。最终必须实际运行并修复发现的问题，交付 README、质量报告、验证命令与结果。
