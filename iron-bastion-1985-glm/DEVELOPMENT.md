# Iron Bastion 1985 — 开发需求词

先按 AGENTS.md 判断本任务需要 Playwright、Midscene.js、Chrome DevTools MCP 中的哪些工具；只使用
必要工具，并说明选择和跳过原因。诊断后必须回到确定性测试复验。

使用 threejs-game-director 技能，所有新文件和操作必须限制在本目录（`iron-bastion-1985-glm/`）内，
不得修改、覆盖或删除父项目已有内容。

## 开发要求

创建一个可玩的高品质 Three.js 单网页游戏，并由 threejs-game-director 自动调用需要的玩法、图形、UI、
音频、调试和 QA 技能，完成设计、开发、性能检查、桌面/移动端适配及全流程验证。不要只做静态场景或简单
Demo，必须具备完整的开始、游玩、胜负、重开和关卡推进闭环。

## 实现内容

制作一款致敬 80 年代 FC 坦克大战玩法、但不直接复制原作素材和商标的原创 3D 坦克守卫游戏。玩家保护
基地并消灭敌军，推进关卡。

操作：

- WASD / 方向键：移动
- Space：开火
- 支持手机触控（虚拟摇杆 + 开火按钮）

至少包含 3 张布局、路线和难度明显不同的地图，具有砖墙、钢墙、水域、树林、不同敌军类型、生命、计分、
增益、暂停、失败重开、关卡过渡和最终胜利。

游戏内所有文字必须统一使用简体中文显示，包括：标题、主菜单/设置、HUD（生命、计分、关卡、增益状态）、
按键提示、暂停/失败/胜利/通关结算。中文字符须使用支持中文的字体，避免方块或乱码；移动端文案不得溢出
或被遮挡。

画面需有统一美术方向、清晰 HUD、命中/爆炸 VFX、音效与 BGM，以及良好的游戏手感。

## 技术与验收

使用 Three.js + TypeScript + Vite。提供确定性测试钩子（固定 seed 可复现关卡布局与敌军刷新）、运行
诊断、生产构建、Playwright 交互测试、桌面与移动端视觉基线、画布非空检查和机器人游玩测试。Playwright/
视觉基线需专门校验中文文案正确渲染、无乱码、无溢出遮挡。最终必须实际运行并修复发现的问题，交付 README、
质量报告、验证命令与结果。未经确认不要 push、创建 PR 或修改父目录。
