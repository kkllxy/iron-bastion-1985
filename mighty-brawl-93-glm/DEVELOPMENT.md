# Mighty Brawl 93 · 霓虹快打 — 开发需求词

先按 AGENTS.md 判断本任务需要 Playwright、Midscene.js、Chrome DevTools MCP 中的哪些工具；只使用
必要工具，并说明选择和跳过原因。诊断后必须回到确定性测试复验。

使用 threejs-game-director 技能，所有新文件和操作必须限制在本目录（`mighty-brawl-93-glm/`）内，
不得修改、覆盖或删除父项目已有内容。

## 开发要求

创建一个可玩的高品质 Three.js 单网页游戏，并由 threejs-game-director 自动调用需要的玩法、图形、UI、
音频、调试和 QA 技能，完成设计、开发、性能检查、桌面/移动端适配及全流程验证。不要只做静态场景或简单
Demo，必须具备完整的开始、游玩、胜负、续关重开和关卡推进闭环。

## 实现内容

制作一款致敬 1993 年 FC《Mighty 快打旋风》清版动作玩法、但不直接复制原作素材和商标的原创 3D Q版
清版动作游戏（Beat'em Up）。玩家控制主角在 3D 斜俯视场景中八方向移动并清剿敌军推进关卡：

- WASD / 方向键：移动
- J / X：普攻（可连段出招）
- K / C：跳跃与跳跃攻击
- L / V：必杀技（消耗怒气槽）
- E / 空格：抓取与投掷敌人
- 支持手机触控（虚拟摇杆 + 攻击/跳跃/必杀/抓取按钮）

至少包含 3 张布局、路线和难度明显不同的关卡（如街区、地铁、地下工厂），每关设有不同敌兵配置与关底
BOSS，最终关有通关演出。敌兵至少包含：普通混混、快速打手、重装壮汉（高血量/护甲）、远程投掷干扰型，
以及各关特色 BOSS。系统需包含：主角血量、命数、计分、经验值与升级解锁新招式（致敬原作升级系统）、
怒气槽必杀、可拾取道具（回血、加分、短暂武器）、暂停、失败续关重开、关卡过渡和最终胜利。

游戏内所有文字必须统一使用简体中文显示，包括：标题、主菜单/设置、HUD（血量、命数、分数、怒气、
经验、关卡进度）、道具说明、按键提示、暂停/失败/胜利/通关结算。中文字符须使用支持中文的字体，避免
方块或乱码；移动端文案不得溢出或被遮挡。

画面需有统一美式卡通/霓虹都市美术方向、Q版 chibi 比例角色、清晰 HUD、命中顿帧/击退/击飞/屏幕震动/
爆烟 VFX、打击音效与 BGM，以及良好的打击手感。

## 技术与验收

使用 Three.js + TypeScript + Vite。提供确定性测试钩子（固定 seed 可复现关卡布局、敌兵刷新与战斗
结算）、运行诊断、生产构建、Playwright 交互测试、桌面与移动端视觉基线、画布非空检查和机器人游玩测试。
Playwright/视觉基线需专门校验中文文案正确渲染、无乱码、无溢出遮挡。最终必须实际运行并修复发现的
问题，交付 README、质量报告、验证命令与结果。未经确认不要 push、创建 PR 或修改父目录。
