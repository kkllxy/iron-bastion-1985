# 钢铁堡垒 1985

一款原创的单网页 Three.js 复古坦克守卫战。灵感来自 8 位机时代的俯视坦克玩法，但模型、地图、界面、名称和声音均为本项目原创实现。

## 开始游戏

```bash
npm install
npm run dev -- --port 5188
```

浏览器打开 `http://127.0.0.1:5188/`。

## 操作

- `WASD` / 方向键：四向移动与转向
- `Space`：开火
- `P` / `Esc`：暂停或继续
- `R`：重新部署
- 手机：左侧摇杆移动，右侧 `FIRE A` 开火

## 玩法

连续守住 3 个战区：边境壁垒（8 辆）、钢铁水网（10 辆）和熔炉围城（12 辆）。每关都有独立的路线、掩体组合、敌军编组与出生节奏；肃清前两关后会在 2 秒内自动转进，完成第 3 关才算最终胜利。失败或按 `R` 会重开当前关，最终胜利后重开则从第 1 关重新开始。

敌军分为侦察、突击和重装三类；砖墙可被炮弹摧毁，钢墙会反弹火花，水域阻挡坦克但不阻挡炮弹，树林可用于隐蔽。每击毁 3 辆敌军会出现反应装甲或装填加速增益。

## 验证

```bash
npm run build
npm run verify:visual
npm run verify:baselines
npm run verify:bot
npm run inspect:canvas -- --url http://127.0.0.1:5188 --state active-play --seed 1985
```

项目内置确定性种子、状态钩子、画布像素检查、桌面/移动截图基线和机器人游玩测试。

## 技术与素材

- Three.js + TypeScript + Vite

- 没有在客户端代码中放置任何生成服务密钥
