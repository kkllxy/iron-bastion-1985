# Burning Saboteur 87 · 夜枭行动 — 开发需求词

先按 AGENTS.md 判断本任务需要 Playwright、Midscene.js、Chrome DevTools MCP 中的哪些工具；只使用
必要工具，并说明选择和跳过原因。诊断后必须回到确定性测试复验。

使用 threejs-game-director 技能，所有新文件和操作必须限制在本目录（`burning-saboteur-87-glm/`）内，
不得修改、覆盖或删除父项目已有内容。

## 开发要求

创建一个可玩的高品质 Three.js 单网页游戏，并由 threejs-game-director 自动调用需要的玩法、图形、UI、
调试和 QA 技能，完成设计、开发、性能检查、桌面/移动端适配及全流程验证。不要只做静态场景或简单 Demo，
必须具备完整的开始、游玩、胜负、重开和区域推进闭环。

## 实现内容

制作一款致敬 1987 年 FC《燃烧战车 / 合金装备》潜行谍报玩法、但不直接复制原作素材和商标的原创 3D
潜行动作游戏。玩家扮演潜入特工，在 3D 斜俯视基地场景中通过潜行、躲避视线与解谜推进，而非一味硬拼：

- WASD / 方向键：移动
- J / X：使用当前武器（持枪射击 / 无声近身制服）
- Shift / Ctrl：贴墙或蹲伏潜行（降低被发现几率）
- E / 空格：互动（开门、拾取道具、救出人质）
- Q / Tab：切换武器与道具
- F / B：进入纸箱躲藏（躲开敌方视线）
- 支持手机触控（虚拟摇杆 + 攻击/潜行/互动/道具/纸箱 按钮）

至少包含 3 张布局、路线和难度明显不同的区域（如基地外围、内部建筑、地下核武库），区域之间相互连通，
需要分级钥匙卡开门、避开巡逻士兵的视线锥与监控摄像头、收集装备情报并救出人质。敌人与机关至少包含：
巡逻士兵（具备视线锥/听觉）、固定监控摄像头、重装守卫、远程狙击手，以及最终可发射核武的直立步行兵器
BOSS（需结合解谜与破坏特定部位击败）。系统需包含：血量、命数、计分、警戒状态机（潜伏→被发现→通缉
→搜查→恢复）、道具与装备（分级钥匙卡、口粮回血、武器、炸药）、救俘虏、暂停、失败重开、区域过渡和
最终摧毁步行兵器的胜利。

游戏内所有文字必须统一使用简体中文显示，包括：标题、主菜单/设置、HUD（血量、弹药、当前道具与钥匙卡
等级、警戒状态、雷达/小地图、区域进度）、道具/任务说明、按键提示、暂停/失败/胜利/通关结算。中文字符
须使用支持中文的字体，避免方块或乱码；移动端文案不得溢出或被遮挡。

画面需有统一冷峻军事/机械美术方向、视线锥可视化/警报闪烁/爆炸/纸箱 VFX、脚步/枪声/警报提示音效与
BGM，以及良好的潜行手感。

## 技术与验收

使用 Three.js + TypeScript + Vite。提供确定性测试钩子（固定 seed 可复现敌人巡逻路线与视线锥）、
运行诊断、生产构建、Playwright 交互测试、桌面与移动端视觉基线、画布非空检查和机器人游玩测试。
Playwright/视觉基线需专门校验中文文案正确渲染、无乱码、无溢出遮挡。最终必须实际运行并修复发现的
问题，交付 README、质量报告、验证命令与结果。未经确认不要 push、创建 PR 或修改父目录。
